# Changelog

## 0.1.0

Initial public release package.

Includes:

- DWARF Mini planetary preprocessing script
- DWARF Mini planetary sharpening/processing script
- README
- installation guide
- workflow guide
- MIT license

### Preprocessing features

- Siril OSC/CFA debayering
- feature-based affine registration
- weighted stacking
- target-based filenames
- FITS metadata copied from selected reference frame
- raw/base outputs

### Processing features

- Soft/Balanced/Strong presets
- Automatic mode
- Basic manual controls
- Advanced mode
- Richardson-Lucy style deconvolution
- edge-aware denoise
- noise-gated detail enhancement
- limb protection
- final output filename selection
