# Examples

Large FITS datasets are not included in this repository because DWARF Mini sequences can be large.

Suggested README screenshots:

1. Raw/linear stack from preprocessing
2. Base stack from preprocessing
3. Final sharpened output
4. Close-up comparison around the lunar terminator

Suggested example folder layout:

```text
examples/
  README.md
  screenshots/
    moon_base.png
    moon_final.png
```

Do not commit large `.fit`, `.fits`, `.fit.fz`, or `.fits.fz` captures unless you intentionally use Git LFS or external release assets.
